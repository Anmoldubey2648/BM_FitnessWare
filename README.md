# BM Fitness Ware

A modern web application for fitness tracking and meal planning with an intuitive user interface built using HTML, JavaScript, and TailwindCSS.

## Features

- **BMR Calculator**: Calculate your Basal Metabolic Rate based on personal metrics
- **Personalized Meal Plans**: Get customized meal plans for both vegetarian and non-vegetarian diets
- **Step Tracking**: Track your daily steps and calories burned using geolocation
- **Workout Management**: Upload and share workout videos with the community
- **Body Analysis**: AI-powered body composition analysis (coming soon)

## Tech Stack

- HTML5
- JavaScript (ES6+)
- TailwindCSS
- Font Awesome Icons
- Google Fonts (Roboto, Montserrat)

## Core Components

### BMR Calculator
- Calculates BMR using the Harris-Benedict equation
- Supports both male and female calculations
- Provides fitness status and global percentile ranking

### Meal Planning System
- Dynamic meal suggestions based on BMR
- Separate plans for vegetarian and non-vegetarian diets
- Calorie-distributed meals across breakfast, lunch, dinner, and snacks

### Step Tracking
- Geolocation-based step counting
- Customizable daily step targets
- Real-time calorie burn calculations
- Progress visualization

### Workout Features
- Video upload and sharing
- Thumbnail generation
- Social features (likes, comments)
- Hashtag support

## Installation

1. Clone the repository
2. Open `v4.html` in a modern web browser
3. Enable location services for step tracking functionality

## Usage

1. Calculate your BMR by entering your metrics
2. Get personalized meal plans based on your BMR
3. Track your daily steps
4. Upload and share workout videos
5. Interact with the fitness community
